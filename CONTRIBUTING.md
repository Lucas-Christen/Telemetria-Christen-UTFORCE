## Diretrizes de Contribuição

### 1. Processo de Desenvolvimento
1. Crie uma branch para cada nova funcionalidade ou correção
2. Mantenha as branches atualizadas com a main
3. Siga as convenções de código existentes
4. Documente todas as alterações significativas

### 2. Padrões de Código
- Siga o estilo de código Python PEP 8
- Mantenha a consistência com o código existente
- Adicione comentários explicativos quando necessário
- Mantenha a interface gráfica consistente com o design atual

### 3. Testes
- Adicione testes para novas funcionalidades
- Mantenha a cobertura de testes existente
- Execute todos os testes antes de submeter alterações

### 4. Documentação
- Atualize a documentação para refletir mudanças significativas
- Mantenha o README.md atualizado
- Documente novas funcionalidades no código

### 5. Pull Requests
1. Descreva claramente as alterações propostas
2. Referencie issues relacionadas
3. Inclua screenshots para mudanças na interface
4. Certifique-se de que todos os testes passam

### 6. Revisão de Código
- Todas as alterações devem ser revisadas
- O Nauber Prestes tem autoridade para aprovar pull requests
- Mantenha discussões construtivas e focadas no código
