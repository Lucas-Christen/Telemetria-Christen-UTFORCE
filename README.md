# Telemetria UTFORCE E-RACING

## Descrição

Aplicativo de telemetria desenvolvido pelo Lucas Fernandes Christen no dia 02/01/2025 para a Equipe de formula SAE Elétrica UTForce E-Racing, utilizando Python e PySide6 para a interface gráfica. Este projeto simula dados de sensores e os visualiza em gráficos interativos.
