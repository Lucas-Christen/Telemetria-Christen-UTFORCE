# Telemetria UTFORCE E-RACING

## Descrição

Aplicativo de telemetria desenvolvido pelo Lucas Fernandes Christen no dia 02/01/2025 para a Equipe de formula SAE Elétrica UTForce E-Racing, utilizando Python e PySide6 para a interface gráfica. Este projeto simula dados de sensores e os visualiza em gráficos interativos.

## Instalação

1. Clone o repositório:
```bash
git clone [URL_DO_REPOSITÓRIO]
```

2. Instale as dependências:
```bash
pip install -r requirements.txt
```

## Uso

Para executar o aplicativo:
```bash
python main.py
```

## Funcionalidades

- Simulação de dados de sensores
- Visualização em tempo real através de gráficos interativos
- Interface gráfica moderna e responsiva
- Suporte a múltiplos tipos de dados e sensores

## Estrutura do Projeto

- `main.py`: Arquivo principal do aplicativo
- `gui/`: Diretório contendo os componentes da interface gráfica
- `data/`: Diretório para armazenamento de dados
- `assets/`: Recursos gráficos e arquivos de configuração
- `tests/`: Testes automatizados

## Requisitos do Sistema

- Python 3.8 ou superior
- PySide6
- Dependências listadas em requirements.txt
